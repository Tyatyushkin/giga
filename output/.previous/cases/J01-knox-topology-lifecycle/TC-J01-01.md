# E2E тест-кейс

## Общая информация

- **ID:** TC-J01-01
- **Название:** Отказ аутентификации: административные запросы с неверным паролем admin
- **Цель:** Подтверждает, что шлюз отклоняет запрос с верным логином admin и неверным паролем ответом HTTP 401 с текстом Authentication failed в теле, что отказ распространяется и на административный PUT деплоя, и что отклонённый PUT не создаёт топологию demo-e2e в реестре
- **Приоритет:** Высокий
- **Journey:** J01-knox-topology-lifecycle
- **Вариант от:** TC-J01-00
- **Покрываемые требования:** REQ-01, REQ-02

## Предусловия

- Предусловия TC-J01-00 действуют без изменений вплоть до его шага 1: шлюз Apache Knox запущен, базовый URL https://knox-demo.local:8443 отвечает по TLS, административный API https://knox-demo.local:8443/gateway/admin/api/v1/topologies доступен.
- Демонстрационный LDAP шлюза содержит ровно две учётные записи: admin / admin-password и guest / guest-password (REQ-01). Пароль wrong-password-2026 в LDAP отсутствует по построению — REQ-01 объявляет в нём ровно эти две записи.
- Отклонение от TC-J01-00 начинается на шаге 1 этого кейса, соответствующем шагу 1 основного кейса: тот же GET-запрос списка топологий выполняется с логином admin и заведомо неверным паролем wrong-password-2026 вместо admin-password.
- Топология demo-e2e не разворачивалась и в ходе этого кейса не создаётся: шаги 3–12 TC-J01-00 в него не входят.
- Файл demo-e2e-topology.xml с XML-описанием топологии (провайдер аутентификации ShiroProvider, сервис WEBHDFS) подготовлен на машине, с которой выполняется прогон (REQ-02).
- Сессия не устанавливается: каждый запрос несёт собственный заголовок Basic-аутентификации (REQ-01).

## Постусловия

- Топология demo-e2e в реестре шлюза отсутствует: записи с таким значением поля name в ответе GET списка топологий нет (шаг 3).
- Реестр топологий и HDFS не изменены: отклонённые на шагах 1 и 2 запросы до сервиса не дошли (REQ-01), а шаг 3 — только чтение списка.
- Сессий и токенов не остаётся: аутентификация выполнялась заголовком Basic на каждом запросе (REQ-01). Очистка после кейса не требуется — артефактов он не создаёт.

## Выявленные пробелы

- **Пробел 2 (нумерация плана J01).** Отказ аутентификации описан только по одной причине. REQ-01: «Запрос с неверным паролем возвращает HTTP 401, тело ответа содержит текст `Authentication failed`». Для логина, отсутствующего в LDAP, для пустого значения заголовка `Authorization` и для запроса вовсе без этого заголовка код и тело ответа не заданы, хотя REQ-01 открывается словами «Любой запрос через шлюз требует Basic-аутентификации». Поэтому кейс проверяет единственную определённую ветку — верный логин плюс неверный пароль (вопрос 1).
- **Пробел 5 (нумерация плана J01).** Стенд не специфицирован: хост в REQ-02 — плейсхолдер «PUT https://<хост>:8443/gateway/admin/api/v1/topologies/<имя>», имя топологии — «<имя>». Значения https://knox-demo.local:8443 и demo-e2e выбраны тестом, режим проверки TLS-сертификата порта 8443 требованиями не задан (вопрос 3).
- **Пробел 6 (новый, выявлен при написании кейса).** HTTP-код операции «GET …/gateway/admin/api/v1/topologies» при верных учётных данных не задан ни одним требованием: REQ-02 и REQ-06 фиксируют только содержимое списка, REQ-01 переадресует код к операции — «код ответа определяется операцией (REQ-02…REQ-06)». Поэтому шаг 3 проверяет тело ответа и не проверяет код (вопрос 2).

## Уточняющие вопросы

1. Какой HTTP-код и какое тело возвращает шлюз для логина, отсутствующего в LDAP, для пустого значения заголовка Authorization и для запроса вовсе без этого заголовка — те же HTTP 401 и Authentication failed, что и для неверного пароля? — блокирует расширение этого кейса на перечисленные ветки отказа (вопрос 2 плана J01, пробел 2).
2. Какой HTTP-код возвращает GET …/gateway/admin/api/v1/topologies при верных учётных данных admin / admin-password? — блокирует проверку кода ответа на шаге 3 (новый вопрос, пробел 6).
3. Какие конкретные хост и порт стенда использовать вместо https://knox-demo.local:8443 и требуется ли отключать проверку TLS-сертификата шлюза? — блокирует шаги 1, 2 и 3 (вопрос 5 плана J01, пробел 5).
