# Требования к шлюзу Apache Knox — администрирование и аудит (демонстрационный набор)

## Администрирование топологий

- **REQ-07.** Запрос `GET https://<хост>:8443/gateway/admin/api/v1/topologies` от роли `admin`
  возвращает HTTP 200 и JSON-список развёрнутых топологий; каждая запись содержит поля
  `name` и `timestamp`.
- **REQ-08.** Запрос `PUT …/admin/api/v1/topologies/<имя>` с XML-описанием топологии
  (провайдер аутентификации ShiroProvider, сервис WEBHDFS) возвращает HTTP 200.
  Не позднее чем через 30 секунд топология появляется в списке из REQ-07,
  и её gateway-URL начинает отвечать на запросы из REQ-03.
- **REQ-09.** Запрос `DELETE …/admin/api/v1/topologies/<имя>` возвращает HTTP 200.
  После удаления gateway-URL этой топологии возвращает HTTP 404 (поведение REQ-06).

## Аудит

- **REQ-10.** Каждый запрос, прошедший через шлюз, добавляет в аудит-журнал строку,
  содержащую имя пользователя, HTTP-метод, URI запроса и код ответа. Строка появляется
  в журнале не позднее чем через 5 секунд после ответа.
